# Snow

맥 화면에 눈을 내리고, 열려 있는 창과 Dock 위에 쌓이게 하는 메뉴바 앱입니다.

- 눈송이는 하늘하늘 흔들리며 떨어지고, 창의 윗변과 Dock 위에 쌓입니다.
- 창을 옮기면 쌓인 눈도 함께 움직이고, 빠르게 흔들면 털려서 흩어집니다.
- 창을 닫으면 그 위의 눈이 떨어집니다. 최소화하거나 다른 데스크톱으로 옮긴 창은 눈을 그대로 가지고 있다가 다시 나타날 때 함께 보입니다.
- 클릭은 모두 아래 창으로 통과하므로 평소처럼 Mac을 쓸 수 있습니다.

## 요구 사항

- macOS 14 이상, Apple Silicon
- Xcode 또는 Command Line Tools (Swift 컴파일러)

## 빌드와 실행

```sh
git clone https://github.com/obb8923/snow.git
cd snow
./build.sh
open build/Snow.app
```

`build/Snow.app`이 만들어집니다. Dock 아이콘 없이 메뉴바에 눈송이 아이콘으로 나타납니다.

## 권한

**손쉬운 사용** 권한은 Dock의 정확한 위치와 크기를 읽는 데만 씁니다. 다른 앱 창의 위치는 권한 없이 알 수 있지만, Dock은 손쉬운 사용 API로만 아이콘 줄의 위치를 알 수 있습니다.

- 권한을 주지 않아도 창 위에는 쌓이고, Dock 위에만 쌓이지 않습니다.
- 허용하려면 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 Snow를 켭니다. 메뉴바 패널의 "손쉬운 사용 설정 열기" 버튼으로도 갈 수 있습니다.
- 앱 ID `com.jeong.snow` 기준으로 서명하므로 다시 빌드해도 권한이 유지됩니다. 목록에 Snow가 켜져 있는데도 Dock에 쌓이지 않으면 −로 지우고 다시 추가하세요.

## 설정

메뉴바의 눈송이 아이콘을 누르면 조절할 수 있습니다. 값은 저장됩니다.

| 항목 | 설명 | 기본값 |
|---|---|---|
| 눈 내리기 | 켜기 / 끄기 | 켜짐 |
| 눈 양 | 화면 넓이당 눈송이 수 | 75 |
| 떨어지는 속도 | 낙하 속도 배율 | 0.8× |
| 눈송이 크기 | 크기 배율. 큰 눈송이일수록 더 많이 쌓입니다 | 1.4× |
| 바람 | 좌우 바람 세기 | 0 |
| 접착력 | 높을수록 가파르게 쌓이고, 창을 흔들어도 덜 털립니다 | 45% |
| 녹는 속도 | 쌓인 눈이 녹는 속도 | 0 |

"쌓인 눈 치우기"로 모든 눈을 한 번에 지울 수 있습니다.

## 동작 방식

- **오버레이**: 화면마다 투명하고 클릭이 통과하는 창을 Dock보다 위에 띄웁니다. 모든 데스크톱과 전체 화면 앱에서 보입니다.
- **내리는 눈**: 일정한 종단속도로 떨어지면서 좌우로 흔들립니다. 흔들림의 양 끝에서 잠깐 느려지고, 높이와 시간에 따라 바뀌는 바람을 받습니다. 뒤쪽의 작고 흐린 눈송이는 깊이감을 위한 것으로 쌓이지 않습니다.
- **쌓인 눈**: 창 윗변과 Dock마다 2pt 폭 기둥들의 높이값(높이맵)을 둡니다. 창 기준 좌표로 저장되므로 창을 옮기면 눈이 함께 움직입니다.
  - 이웃 기둥과의 높이 차가 안식각을 넘으면 넘친 만큼 옆으로 흘려보냅니다. 안식각은 접착력에 따라 25°~75°입니다.
  - 끝으로 갈수록 허용 경사를 완만하게 해서 둥글게 얇아지며 끝납니다. 넘친 눈은 덩어리로 떨어져 아래쪽 창이나 Dock에 다시 쌓입니다.
  - 둥근 창 모서리(양 끝 16pt, Dock은 20pt)에는 쌓이지 않습니다.
- **겹친 창**: 뒤 창의 윗변이 앞 창이나 앞 창에 쌓인 눈 표면보다 아래에 있으면, 그 구간은 가려진 것으로 보고 눈을 쌓거나 그리지 않습니다. 원래 있던 눈은 보관했다가 앞 창을 치우면 다시 보여줍니다.
- **털기**: 창의 속도와 가속도를 매 프레임 추적합니다. 가속도가 마찰(옆 방향)이나 중력(아래 방향)이 버틸 수 있는 한도를 넘으면 넘은 만큼 눈이 털리고, 털린 눈은 창이 가던 방향으로 흩어집니다. 일정한 속도로 옮기면 그대로 따라옵니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `Sources/SnowApp.swift` | 앱 진입점, 메뉴바 설정 패널, 화면 갱신 루프 |
| `Sources/SnowEngine.swift` | 눈송이, 쌓인 눈 높이맵, 털기, 겹친 창 처리 |
| `Sources/Overlay.swift` | 화면별 투명 창과 그리기 |
| `Sources/WindowTracker.swift` | 창 목록과 Dock 위치 읽기 |
| `Sources/Settings.swift` | 설정값 저장 |
| `build.sh` | `build/Snow.app` 빌드와 서명 |

## 알려진 제한

- 눈 양을 크게 올리면 CPU 사용량이 늘어납니다. 그리기를 CPU에서 하기 때문입니다.
- 정식 개발자 인증서가 아닌 임시(ad-hoc) 서명이라, 다른 Mac에 복사해 실행하면 Gatekeeper 경고가 뜰 수 있습니다. 직접 빌드해서 쓰는 것을 권장합니다.
